# Lefouzèbreizh Design System V1

## Mission
Créer une signature visuelle reconnaissable sur tous les sites et applications : premium, moderne, immersive, performante et accessible.

## ADN visuel
- Marque mère : Lefouzèbreizh
- Emblème : zèbre double exposition Bretagne
- Symboles : hermine bretonne fidèle, phare, mer, falaises, mégalithes, oiseaux marins, bruyère, granit et lichens
- Palette : noir profond, turquoise #40E0D0, violet #7C3AED, ambre #F4B850, blanc cassé #F8F8F8
- Principe : spectaculaire dans les moments de marque, extrêmement lisible dans les moments d’usage

## Règles
1. Le zèbre complet est réservé aux moments hero, branding et onboarding.
2. Les interfaces utilisent surtout palette, gradients, hermine, rayures discrètes et lumière.
3. L’hermine doit toujours utiliser une géométrie de référence validée.
4. Les références bretonnes doivent être documentées avant stylisation.
5. Les effets 2.5D/3D sont progressifs et dégradables sur mobile.
6. Toute animation respecte prefers-reduced-motion.
7. Aucun effet ne doit dégrader lisibilité, contraste, performances ou navigation clavier.

## Immersive System
Ocean / Atmosphere / Light / Wildlife / Depth / Motion / Sound / Interaction.
