# Kits

Ce qui a marché quelque part et se recopie ailleurs sans réfléchir : gabarit de
composant, prompt éprouvé, structure de script, bloc de configuration.

Un kit entre ici quand il a servi **deux fois**. Une seule fois, c'est une
solution ; deux fois, c'est un motif — et c'est à ce moment qu'il vaut le coût
de l'extraire.

Chaque kit porte un `README` d'une ligne : à quoi il sert, et où il a déjà servi.
Sans cette ligne, personne ne saura dans trois mois si le kit est encore bon.
