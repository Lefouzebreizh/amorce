# Ensemble face au chômage

Copilote de première orientation pour les personnes qui perdent leur emploi,
arrivent en fin de droits ou préparent une activité. L'outil ne calcule pas de
droits : il transforme une situation déclarée en prochaines actions et renvoie
vers les organismes compétents.

## Principes

- aucune donnée personnelle enregistrée ;
- aucun montant ou droit garanti ;
- sources institutionnelles clairement distinguées ;
- parcours utilisable sur téléphone avant toute lecture longue.

Ouvrir `index.html` dans un navigateur pour utiliser le prototype.
